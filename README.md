# Бот-помощник Натальи Тимошиной
## Мессенджер Max | massagestart.ru

### Что умеет бот

- **Приветствие** — /start с меню из 3 кнопок
- **Диагностика** — 6 вопросов → определение одного из 6 сценариев → персональный результат с оффером PDF
- **Бесплатные материалы** — чек-листы и гайды (файлы подключаются отдельно)
- **Подбор продукта** — 2 вопроса → персональная рекомендация (курс / PDF / менторинг)
- **Цепочка прогрева** — 7 дней автоматических сообщений после /start
- **Теги** — каждое действие пользователя сохраняется как тег для сегментации

### Структура файлов

```
massage_bot/
├── bot.py           — главный файл, запуск бота
├── storage.py       — хранение данных пользователей (JSON)
├── keyboards.py     — все клавиатуры (inline-кнопки)
├── texts.py         — все тексты сообщений
├── scenarios.py     — логика определения сценария
├── requirements.txt — зависимости
└── README.md        — этот файл
```

### Как запустить

#### 1. Установить Python 3.10+

Скачайте с https://python.org

#### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

#### 3. Вставить токен бота

Откройте `bot.py`, найдите строку:
```python
TOKEN = os.environ.get("BOT_TOKEN", "ВСТАВЬТЕ_ВАШ_ТОКЕН_СЮДА")
```

Замените `ВСТАВЬТЕ_ВАШ_ТОКЕН_СЮДА` на ваш токен из Max.

Или задайте переменную окружения:
```bash
export BOT_TOKEN=ваш_токен_тут
```

#### 4. Запустить

```bash
python bot.py
```

### Развёртывание на Bothost.ru

1. Создайте репозиторий на GitHub
2. Загрузите все файлы из папки `massage_bot/`
3. Зарегистрируйтесь на https://bothost.ru
4. Подключите GitHub-репозиторий
5. В настройках укажите переменную окружения `BOT_TOKEN`
6. Бот запустится автоматически

### Как добавить бесплатные материалы (PDF/файлы)

1. Создайте файлы чек-листов (PDF)
2. Загрузите их в репозиторий в папку `files/`
3. В `bot.py` в секции обработки `mat_*` замените текст-заглушку на:
```python
await bot.send_file(chat_id=chat_id, file=open("files/checklist.pdf", "rb"))
```
